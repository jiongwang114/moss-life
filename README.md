# MOSS

## 项目简介

MOSS 是一款面向个人生活记录的应用，帮助你随手记下经历、想法和感受，再通过 AI 辅助整理、标签归类与语义搜索，重新找到值得回看的内容。

写下一段话，留住当下；沿着时间、分类和搜索，再次遇见自己的记录。下载安装客户端，或直接打开网页版，即可连接 MOSS 提供的服务使用。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 随手记录 | 写下经历、想法和感受，支持 Markdown；草稿和待发送内容在本地暂存。 |
| AI 辅助整理 | 辅助整理正文、生成标题并归类标签，方便后续浏览与回看。 |
| 浏览与筛选 | 按时间和分类查看记录，支持修改标题、删除标签和删除记录。 |
| 智能搜索 | 用自己的话描述想找的内容，检索意思相关的已完成记录。 |
| 数据导出 | 将已完成的记录导出为 Markdown 和 ZIP，保存一份自己的副本。 |
| 账号管理 | 支持昵称和密码修改、切换账号、退出全部设备、推荐码邀请及账号注销。 |

## 安装与访问

### Android

适配目标为 Android 8.0 及以上。下载 MOSS 安装包，在手机上打开并按照系统提示完成安装，然后启动应用。

**[下载 Android 最新版](https://note.jiongplay.cn/api/v1/app-updates/android/packages/17)** · [查看历史版本](https://github.com/jiongwang114/moss-life/releases)

点击最新版链接即可下载 APK；GitHub 历史发布页的 **Assets（下载附件）** 中保留旧版安装包。

### 网页版

用浏览器打开 [MOSS 网页版](https://note.jiongplay.cn)，登录后使用。

客户端和网页版使用 MOSS 提供的服务，使用者无需安装开发环境、配置 AI 密钥或部署服务器。

## 使用方法

1. **注册与登录**：没有账号时，获取有效的邀请码或已有用户分享的推荐码，在注册页的“邀请码”栏填写，选择未被占用的账号名并设置密码；已有账号直接登录。
2. **写下记录**：进入“写记录”，输入内容后发送，等待正文、标题和标签处理完成。上一条尚未完成时，可以继续写草稿，完成后再发送下一条。
3. **回看与搜索**：进入“看记录”，按时间浏览或选择分类筛选，也可以输入描述查找相关内容。分类模式下需先选择分类；切换到“按时间”可搜索全部记录。
4. **导出留存**：打开“账号与设置 → 导出我的记录”，按页面提示生成 ZIP 并保存；Android 端通过系统文件选择器选择保存位置。
5. **邀请朋友**：打开“账号与设置 → 我的推荐码”生成推荐码。每个账号同时只有一个有效码，7 天内有效，仅供一人注册；使用或过期后可重新生成。

断网时可先保留草稿和待发送内容，恢复网络后按页面提示手动发送。AI 整理、云端浏览和搜索需要连接服务；处理失败时按提示重试或继续。

## 当前状态与数据说明

项目仍在持续迭代，当前仓库源码版本为 **0.3.7**。当前 Android 安装包由 MOSS 下载服务提供，GitHub 历史版保留供查阅；不同手机及厂商 WebView 的实际兼容性仍需真机验证。

安卓 0.3.6 起支持启动检查和“账号与设置 → 检查更新”。运营方发布版本信息后，App 才会提示；同意后下载，由安卓系统确认安装。0.3.5 及更早的版本需先手动覆盖安装一次，才能获得检查更新功能。0.3.7 的版本接口及安装包已部署，并通过连接正式 HTTPS 服务的真机检查。

- **数据保存**：账号和已发送的记录保存在服务器中，手机或浏览器还会保存草稿、会话及待发送内容。记录并非仅存储在手机上。
- **AI 处理**：启用在线 AI 时，处理所需的记录正文会发送至服务端配置的 AI 服务，用于整理正文、生成标题和匹配标签；具体提供方及数据处理政策以实际服务配置和说明为准。
- **留存与注销**：建议定期导出重要记录。注销账号会清理账号及相关在线数据，不提供恢复；自行下载的文件、其他离线设备上的内容和服务器历史备份有各自的清理边界，详情见应用内“数据与隐私说明”。
